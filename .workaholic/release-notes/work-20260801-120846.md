# State the sample behind generational verdicts

## Summary

The generational delta section reported directions without the sample they rested on, so "−38%, regressed" was unreadable as a claim. The delta table now carries the contributing trial count per metric, and the two open sampling questions are answered and recorded as an ADR.

## Key Changes

- A **Trials** column drawn from each metric's own contributing-trial count — per metric, not per run, because the structural probes execute once while the speed probe repeats.
- `--trials` is deliberately not raised: more trials cannot move this gate at all.
- Verdicts stay per effort level, since `low`/`medium`/`high` are different operating points rather than repeated samples.

## Changes

### Added
- `docs/adr/0008-generational-verdict-sampling.md` recording both sampling decisions, plus a ticket for the real lever the analysis exposed.

### Changed
- The generational delta table states the sample behind every direction it reports.
