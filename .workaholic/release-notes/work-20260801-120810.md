# Guard committed history frames against survey-series blocks

## Summary

Committed history frames are now asserted, not just normalized on write. A regression guard reads every frame under `docs/research-reports/history/` and fails on the survey-series blocks and in-frame links the archive contract forbids. It found a real stale frame on its first run.

## Key Changes

- Added `history-frames.test.ts`, asserting every committed frame carries no `](./history/` link and neither survey-series block (推移 / 過去の調査).
- Exported `TREND_LABEL` / `RELATED_LABEL` from `domain/current-article.ts` so the guard shares the renderer's constants and cannot go vacuous on a rename.
- Normalized the one non-conformant frame (`token-metering/2026-07-17T03-02-34-699Z`) by running the repo's own `stripSurveyBlocks` over it.
