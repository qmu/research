# Make the comparison record reproducible from committed frames

## Summary

The record behind the published LLM comparison tables existed only as a gitignored, machine-local file on one checkout, so a fresh worktree silently degraded a scoped sweep into the whole record. The record is now rebuilt from committed history, and a scoped run with no base refuses instead of narrowing.

## Key Changes

- A scoped run with no base now refuses, naming both searched locations and both remedies; "first full run" and "scoped run with no base" are no longer one code path.
- The record is reconstructed by folding every committed frame through the existing `mergeConfigs` — no second artifact committed.
- `--render-latest` renders that reconstruction, and the projection into the published pages refuses any narrowing, reporting both counts.

## Changes

### Added
- Reconstruction of the comparison record from committed history frames, and a refusal path for a scoped run with no base.

### Changed
- `--render-latest` renders the reconstruction; the page projection reports and rejects row-count narrowing.
