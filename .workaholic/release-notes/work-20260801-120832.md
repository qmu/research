# Guard the exporter against downstream overwrite

## Summary

`scripts/publish-research.sh copy` writes into a directory it shares with hand-authored prose on qmu-co-jp, and every re-run silently replaced downstream edits. The exporter now has an ownership boundary, stated in the tool and proven in CI.

## Key Changes

- A committed ledger (`scripts/publish-ledger.tsv`) records the sha256 of what the exporter last emitted per destination; a destination it cannot prove it wrote is skipped loudly, and the run continues.
- `--force` is the explicit override; `--dry-run` refuses too and writes nothing.
- `make publish-guard` (`scripts/check-publish-guard.sh`, 9 assertions) runs in CI and is mutation-tested.

## Changes

### Added
- Publish ledger, pre-write ownership check, `--force` override, `make publish-guard` target and its CI step.

### Changed
- The exporter's header states the ownership boundary: never authored downstream means this repo wins; authored downstream means qmu-co-jp wins.
