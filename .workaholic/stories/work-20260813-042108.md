## 1. Overview

A long report is translated in about fifteen calls, and each call sees only its
own slice — so a term written in call 3 is re-invented in call 14. This branch
gives every chunk the same glossary and adds a check that costs nothing to run.

**Highlights:**

1. The glossary rides every chunk, because the chunk boundary is what loses the context
2. `npm run check:glossary` — no API calls, so a regression costs milliseconds rather than $7.20
3. It found a fourth drift the ticket did not name, where the *forbidden* form is the more frequent one

## 2. Motivation

One published article gives the same table row two names: nine blocks read
`総合判定: **mixed**` and the tenth reads `総合評価: **まちまち**`. The numbers
were checked figure by figure and are correct, so nothing was wrong except that
a reader has to work out that two different labels mean the same thing. Nothing
detected it — the byte-stability fixtures cover the keyless English path, not the
paid Japanese one — and each pass that could reveal it costs real money.

## 3. Changes

### 3-1. The Japanese translator names the same field two different ways inside one page ([5aa8564](https://github.com/qmu/research/commit/5aa8564))

Adds the term map and injects it into `buildTranslationPrompt`, so it reaches
every chunk; adds `findGlossaryDrift` and the `check:glossary` runner over the
published pages. The glossary states the synonym it forbids, not just the term to
use, because the failure being prevented is a plausible alternative.

## 4. Outcome

The mechanism is closed at both ends — prevented in the prompt, detected in the
output — and the detection half is proven against the real defect.

## 5. Concerns

### The check is not in `make lint` yet, which is where it belongs

- **Severity:** moderate
- **Description:** The ticket asks for it to sit in `make lint`, but the pages it currently fires on are its own designated regression fixtures, so wiring it in now makes CI red on content that must not be touched (see [5aa8564](https://github.com/qmu/research/commit/5aa8564) in `packages/tech/src/entrypoints/check-translation-glossary.ts`)
- **How to Fix:** Wire it in as the last step of the regeneration, in the same change that updates the two fixture cases — the ordering is the only reason it is a separate script

### Prevention is unproven until a page is regenerated

- **Severity:** moderate
- **Description:** A test asserts the glossary reaches a built chunk prompt, but whether the model then honours it across fifteen calls is not established by anything here, and only a paid pass can establish it (see [5aa8564](https://github.com/qmu/research/commit/5aa8564) in `packages/tech/src/research/domain/translate.ts`)
- **How to Fix:** Run the next pass and check the output; if drift survives the glossary, the ticket's step 3 — translating the parallel generational blocks as one unit — is the fallback it anticipated

### Two canonical renderings were chosen, not derived

- **Severity:** low
- **Description:** `判別不能` over `区別不能` and `mixed` over `まちまち` were picked by frequency across the committed pages and by which form the defining paragraph uses; both alternatives are defensible Japanese and the point is consistency, not correctness (see [5aa8564](https://github.com/qmu/research/commit/5aa8564) in `packages/tech/src/research/domain/translation-glossary.ts`)
- **How to Fix:** Change the canonical value in one place if the house style differs; the checker and the prompt both read it from there

## 6. Successful Development Patterns

- Building the detector before the fix could be proven turned an unverifiable change into a verifiable one: the prevention needs a paid pass, but the detection fires today, against the real defect, for free.
- Measuring the drift before writing the glossary is what surfaced the fourth instance — the speed page's `区別不能` ×3 against `判別不能` ×2, where the drifted form is the *majority*, which reading the ticket alone would not have suggested.
