# Auto-deploy docs to a Cloudflare Worker on merge to main (staging-research.qmu.co.jp)

When a pull request is merged to `main` on this repository, the documentation site should be deployed automatically to a Cloudflare Worker serving `staging-research.qmu.co.jp`.

Reported via Slack by tamura_yoshiya on 2026-08-18 and filed as a GitHub issue. The filing states that no investigation into the repository or its deployment setup was done as part of raising it.

Source: https://github.com/qmu/research/issues/115
